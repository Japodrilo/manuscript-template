## Manuscript template

This is a LaTeX template to quickly start a new mathematics manuscript.
The easiest way to use it is to create a new repository with the `Use this
template` green button on the top right corner of this page.

It is not a good idea to clone or fork this repository.   In the former case,
you will not have a personal copy to modifiy and push changes.   In the latter
case, you will copy the commit history of this repository.   By creating a new
repository and using this one as a template, you will have your own personal
copy with a clean commit history.
